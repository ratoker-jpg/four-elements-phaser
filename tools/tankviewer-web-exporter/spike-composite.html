Проверка композитной текстуры TankViewer

Проверка формулы TankViewer для Wasp M0. Формула: HARDLIGHT(colormap, MULTIPLY(lightmap, details)).

Схема направлений: dir0=E, dir1=SE, dir2=S, dir3=SW, dir4=W, dir5=NW, dir6=N, dir7=NE (8 направлений)
dir0=E, dir1=ESE, dir2=SE, ..., dir12=N, ..., dir15=ENE (16 направлений)
Совпадает с directionFromDelta() игры.

Config.xml / каталог моделей

Загрузи config.xml из TankViewer, чтобы инструмент сам подсказал нужные файлы модели, details и lightmap. Сами файлы всё равно нужно выбрать вручную ниже — браузер не может читать пути на диске автоматически.
