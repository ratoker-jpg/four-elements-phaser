TankViewer Web Sprite Exporter

UNIT-ASSET-PIPELINE-02A: Browser-based 3DS → isometric sprite exporter. Uses Three.js TDSLoader. No Blender required. dir0 = E convention.

Direction convention: dir0=E, dir1=SE, dir2=S, dir3=SW, dir4=W, dir5=NW, dir6=N, dir7=NE (8-dir)
dir0=E, dir1=ESE, dir2=SE, ..., dir12=N, ..., dir15=ENE (16-dir)
Matches game's directionFromDelta().
