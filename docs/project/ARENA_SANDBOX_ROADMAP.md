## 1. Главная цель

Сделать отдельный режим **Арена** для ручного тестирования боевых юнитов.

Арена должна позволять владельцу быстро создавать боевые ситуации вручную:

```text
выбрал корпус → выбрал пушку → выбрал сторону → поставил юнита → тестируй движение / башню / стрельбу / урон
```

Арена нужна для тестирования:

- движения юнитов;
- поворота корпуса;
- поворота башни;
- наведения на цель;
- стрельбы;
- отдачи;
- урона;
- HP / уничтожения;
- союзники против врагов;
- позже — простых режимов поведения врагов.

# Шаг 3 — ARENA-02H+ — Создание и расстановка юнитов

## Цель

Добавить главный инструмент арены: ручное создание и расстановку юнитов.

Этот шаг объединяет создание юнита и placement по клику, потому что по отдельности они дают слишком мало игровой пользы.

## Что добавляем в Arena Menu

### Выбор корпуса

- Wasp;
- Hornet;
- Hunter;
- Viking;
- Dictator;
- Titan;
- Mammoth.

### Выбор пушки

- Smoky;
- Thunder;
- Railgun;
- Shaft;
- Flamethrower;
- Freeze;
- Isida;
- Vulcan;
- Twins;
- Ricochet;
- Hammer.

### Выбор стороны

- союзник;
- враг.

### Действия

- создать / разместить юнита;
- отменить размещение.

## Как работает размещение

```text
1. Игрок выбирает корпус.
2. Игрок выбирает пушку.
3. Игрок выбирает сторону.
4. Игрок нажимает «Разместить».
5. Кликает по арене.
6. Юнит появляется в точке клика.
7. Esc или правая кнопка мыши отменяет размещение.
```

## Главное правило

Код не выбирает комбинацию корпус+пушка сам.

Неправильный основной поток:

```text
Hunter + Smoky
Hornet + Ricochet
Mammoth + Thunder
```

Правильный основной поток:

```text
пользователь выбрал корпус → пользователь выбрал пушку → пользователь выбрал сторону → поставил юнита
```

## Ожидаемый результат

Можно вручную создать любого союзного или вражеского юнита из любого доступного корпуса и пушки и поставить его на арену кликом.

# Шаг 4 — ARENA-03H+ — Управление, цели и правила башни

## Цель

Настроить корректную боевую логику для арены:

- союзники управляемые;
- враги неуправляемые;
- враги являются целями;
- башня наводится на выбранного врага, а не на указатель мыши.

## Союзники

Союзного юнита можно:

- выбрать;
- двигать;
- назначить цель;
- заставить стрелять;
- тестировать в бою.

## Враги

Вражеского юнита нельзя контролировать.

Враг должен:

- стоять на арене;
- быть целью;
- получать урон;
- терять HP;
- уничтожаться.

## Новое правило башни

Текущее поведение, при котором башня следит за указателем мыши, не подходит для арены.

Нужна логика фиксации на цели:

```text
1. Игрок выбирает союзного юнита.
2. Игрок кликает по вражескому юниту как по цели.
3. Этот враг становится выбранной целью.
4. Башня союзного юнита наводится на эту цель.
5. Если союзный танк объезжает врага, башня продолжает смотреть на врага.
6. Указатель мыши больше не управляет направлением башни.
```

## Пример нужного поведения

Вражеский танк стоит в центре арены.

Игрок выбирает союзный танк, кликает по врагу как по цели и начинает объезжать врага.

Ожидаемо:

- корпус едет туда, куда приказано;
- башня остаётся наведена на врага;
- пушка не бегает за указателем мыши.

## Что должен решить аудит

Аудит должен предложить точную техническую схему:

- каким кликом назначается цель;
- как снять цель;
- что делает башня без цели;
- что делает башня при уничтожении цели;
- должна ли башня удерживать последний угол или возвращаться по корпусу.

## Предварительное предпочтение

Рекомендуемая первая версия:

- клик по врагу назначает цель;
- башня смотрит на цель;
- если цель уничтожена, башня держит последний угол;
- отдельная кнопка или Esc может сбросить цель;
- мышь не управляет башней постоянно.

## Ожидаемый результат

Можно создать союзника, создать врага, выбрать союзника, назначить врага как цель, объезжать врага — башня при этом продолжает смотреть на врага.

# Шаг 5 — ARENA-04H+ — Список юнитов и управление ареной

## Цель

Добавить удобное управление текущей тестовой сценой арены.

## Что добавляем

Список всех размещённых юнитов.

В списке видно:

- корпус;
- пушку;
- сторону;
- HP;
- состояние: жив / уничтожен.

## Действия

- выбрать юнита из списка;
- удалить выбранного юнита;
- очистить всех юнитов;
- очистить только союзников;
- очистить только врагов;
- сбросить арену;
- повторить размещение похожего юнита.

## Ожидаемый результат

Можно быстро управлять тестовой сценой без ручной возни.

Примеры:

- создать 3 союзников;
- создать 5 врагов;
- удалить одного врага;
- очистить всех врагов;
- оставить союзников;
- сбросить арену.

# Шаг 7 — ARENA-06H+ — Режимы поведения врагов

## Цель

Добавить простые режимы поведения врагов.

Это нужно, чтобы тестировать не только неподвижные цели, но и первые боевые ситуации.

## Режимы поведения

### Пассивная цель

Враг стоит на месте и получает урон.

### Стоячий стрелок

Враг стоит на месте, но стреляет по союзнику.

### Преследователь

Враг едет к союзнику и пытается стрелять.

### Охрана позиции

Враг стоит в зоне и стреляет, если союзник рядом.

## Ожидаемый результат

Можно тестировать бой против простого противника:

- враг стоит;
- враг стреляет;
- враг преследует;
- враг удерживает позицию.
